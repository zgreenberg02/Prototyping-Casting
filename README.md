# Prototyping-Casting
Foundry operations, additive manufacturing, and student mentoring at Georgia Tech's Flowers Invention Studio. Direct hybrid metal casting using 3D-printed patterns alongside FDM, SLA, and SLS rapid prototyping. Support manual metalworking, woodworking, and electronics workstations, guiding 100+ makers from CAD models to functional hardware.
